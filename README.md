# Forza Livery Agent Workflow

**把这个 GitHub 链接交给 Agent，用自然语言、参考图、截图和圈线，制作可编辑的 FH6 车辆涂装。**

[English](README.en.md) · [Agent 从这里开始](AGENTS.md) · [技能入口](SKILL.md) · [安装与使用](docs/QUICKSTART.md) · [工具与许可证](THIRD_PARTY.md)

用户描述主题和车型，Agent 收集资料、给出设计预览，随后处理人物与背景、原始车辆投影、图层预算、跨面和车窗衔接，生成可编辑 `.3so`。用户可以在任何阶段用自然语言或标注截图提出修改。文字、Logo、Q 版等小贴纸独立分组，推荐最后由用户拼贴微调，也支持委托 Agent 摆放。

**这是一种交互式制作方式，可能需要多轮用户视觉审查、评估和修改。** 生图、拟合和自动检查会有局限；文件校验成功不代表角色像、构图好或接缝合格。默认保留角色官方原始形象与指定形态的特征，用户另有要求时遵循用户要求。

## 用户只需这样开始

把仓库链接和这段话发给有本地工具能力的 Agent：

> 请阅读这个仓库的 README、AGENTS.md 和 SKILL.md，按说明自行配置工具。在你能操作的 Windows 电脑上，为【精确车型、年份及是否 FE】制作【主题/角色/形态】涂装。参考图在这里，素材也可由你收集。先给我两个设计预览，选定后制作。人物和背景由你完成，预留小贴纸层数。默认忠于官方角色形象；我会用自然语言、截图和圈线审查和要求修改，可能不止一轮。

无需先向用户索要坐标、代码或 API Key。Agent 的具体入口是 [AGENTS.md](AGENTS.md)：自动下载校验工具、建立独立环境、查找游戏目录并执行合成自检，只在必要信息无法自动获得时询问用户。

## 到手使用的条件

|需要|说明|
|---|---|
|能看图、读写文件和执行命令的 Agent|不限提供商。推荐 GPT-6.1 Sol/max 或能力接近/更强的多模态模型；这是项目经验建议，不是跨模型排名|
|能参考原图并精确修改的生图模型|优先使用 Agent 所在产品已有的生图工具/订阅；仓库不强制 OpenAI API 或另一个付费 API。未接通时可由用户生成，再把文件交回 Agent|
|Windows x64 和用户自己的 FH6 资源|完整预览、Custom 与本地存档导入目前以此平台为目标；游戏模型/纹理不附送。其他系统可作设计与部分二维处理，完整上车需 Windows 主机|
|网络与本地计算资源|首装下载依赖，拟合消耗 CPU/时间；模型订阅本身不会赋予纯聊天窗口本地工具权限|

Agent 可运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\bootstrap.ps1 -Workspace C:\LiveryProjects
```

可加 `-ToolsRoot` 或 `-GameContent`，按当前电脑配置。Windows 发布入口无需全局安装 Python/编译器，不修改关联，不启动游戏或 FLS，默认 FLS 1.3.0。见 [Quickstart](docs/QUICKSTART.md)。

## 工作流

```mermaid
flowchart LR
  A[主题 车型 参考图] --> B[官方形象与车辆几何核对]
  B --> C[多方案生图预览]
  C --> D[用户选择与反馈]
  D --> E[人物背景母稿与预算]
  E --> F[原生拟合 跨面与窗续贴]
  F --> G[二维与离屏实车审查]
  G --> H{用户视觉审查}
  H -->|自然语言或圈图修改| E
  H -->|接受| I[独立小贴纸与用户微调]
  I --> J[按要求导入本地存档]
  J --> K[用户在游戏中应用 保存 发布]
```

本工作流目前只在痛车上完整测试；其他主题可按需使用其中的设计、拟合与检查环节。

人物、背景、光向、母稿缺陷、清晰度、预算、接缝、文字或 Q 版，任意部分都可以重做。查看实际图像，不用脚本 PASS 代替视觉验收。串珠状重复纹理、发丝与景物融合等先修母稿；反复修改劣化时回可靠原图重生。

跨窗续贴使用同一母稿与实际三维/UV坐标配准，各面独立预算和分组，见 [几何与接缝](references/geometry-and-seams.md)。新设计也选定实际车身漆色，默认随涂装主色；玻璃、刹车、轮圈单独处理。

## 配套工具

- 自制 C++ CPU 拟合器源码、对应 Windows 发布程序、原生模板、加权/种子/冻结优化、DAT 转 `.3so` 与预算检查。
- 人物背景组装、许可遮罩/网格观察、世界坐标场、离屏预览包装器、实际 FLS 用户上下文的 Custom 合并/精确替换。
- [Workbench](https://github.com/lin522026298/FH6-Livery-Workbench) 无界面的自制作品转换、校验、备份、导入和读回工具；对应源码、测试和模块清单随附。
- 自动安装与固定版本/哈希清单。第三方 FLS 和已开源 FH6Preview 直接引用原仓库发行包，保留来源及许可；不为依赖而无意义地复制整个上游。
- 合成拟合、原生导出、隔离存档、Custom 合并、滚动备份及路径边界测试，新环境 CI。

## 导入、备份和发布

Agent 按要求把完整工程转为用户私人原生存档；游戏关闭后只操作文件并读回。整个工作区完整存档备份滚动留一份：先建并核验新备份，导入及全量读回成功后才删旧完整 ZIP，清单/日志保留。损坏报告或导入失败时暂停清理、保留相关备份并先处理问题。

用户在游戏中应用涂装、进入涂装页面保存、发布并核实共享。生成 `.3so` 或本地写入不等于游戏视觉确认或在线发布。

## 验证范围

已有实际制作、跨面/窗续贴及用户导入经验。本仓库另有可重复合成测试与新环境安装检查。此前一次完全独立生成试验虽技术通过，用户仍指出形象偏差，其美术通过结论已撤回。**流程可执行与具体作品达到审美/角色一致性要求须分别验收，多轮用户反馈属于工作流。** 见 [验证说明](docs/VALIDATION.md)，不保证任意车型、模型或风格一次完成。

仓库不含用户存档、身份、账号、密钥、真实 Custom 或历史角色素材。安装配置及项目放 Git 忽略的本地目录或仓库外。敏感信息报告见 [SECURITY.md](SECURITY.md)。
